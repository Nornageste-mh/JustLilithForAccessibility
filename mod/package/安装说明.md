## 这个补丁做了什么

设计目标是两件事：**让界面能听、能不用鼠标操作**；**把选项读出来并能用数字键选**。
台词本身交给游戏语音（本作全程配音）。下面是逐项状态：
「**已实机验证**」= 2026-10-22 在游戏里真的听到 / 按到过；
「已实现」= 代码路径在了，但没有逐项实机核对。

| 功能 | 挂载方式 | 当前状态 |
|---|---|---|
| 菜单 / 设置 / 画廊 / 聊天键盘导航 | 每帧扫描 uGUI `Selectable`（不用挂载点） | **已实机验证**（设置面板 8 个 tab） |
| 控件朗读：按钮 / 开关 / 滑条 / 下拉 / 输入框 / 图标 | 平台层 `Describe` + 逐作标签（`UiNav.Game.cs`） | **已实机验证** |
| 回车激活后重扫并播报「界面已更新」 | `UiNav.cs` | **已实机验证** |
| 朗读选项 + 数字键直选 | `Choices.cs`（`DialogueNode.HasOptions` / `PlayerLineController`） | **已实机验证** |
| 台词朗读（无配音行才念） | `Reader.cs`：对话事件订阅 + 每帧轮询兜底 | 已实现；**默认关**（本作全程配音） |
| 配音判定（有配音就不重复念） | `ResolveNodeSoundId` / `TryGetVoiceSoundId` | 已实现；逐句效果尚未核对 |
| 界面浮动文本（提示条 / 开场字幕） | `ScreenText.cs`：0.22 秒扫可见 `TMP_Text` | 已实现；开场字幕是否覆盖**尚未实机验证** |
| 退出前二次确认 | `[界面导航] 退出确认对象名`（默认 `quitGameButton`） | 已实现（值来自反编译实查） |
| 重读上一段（`Backspace`） | 重读缓冲区 | 已实现（平台层） |
| 沉默键（`0`） | 清补丁自己的待选列表 | 已实现；本作无限时选择，平时无效 |
| 启动播报「无障碍补丁已加载」 | `Awake` 里念一句 | 已实现 |
| 限时选择的倒计时放宽 | — | **本作没有限时选择**，配置项为保留字段 |
| 手机 / 聊天消息自动播报 | — | **未实现**（面板内可导航逐条听） |

### 已知的不足（2026-10-22 实机结论）

- **生日行**：那个「开关」其实是**展开日历**，「生日」行的状态语义仍待修；
  展开后日历格 `DateCell` 念「14，按钮」，**没有日期语义**。
- **`Btn_FolderSelect`**：「我」tab 里被行标题覆盖，念成「你的名字，按钮」；
  真实含义是「选择文件夹」（同一控件在「声音」tab 里是对的）。
- **导航内方向键 / 滑块左右 / PageUp / PageDown 未逐项实测**：
  本轮自动化注入不了方向键，只实测了「导航开关」与「回车」。
- **导航中不静默游戏热键**：本作输入走 native，没有可拦的托管入口，这是已知取舍。
- **开场「记忆相框」字幕读不到**：探针对全部 `TMP_Text` / `Text` 关键字全量扫描 0 命中，
  疑似烘焙在图片或视频里；因本作全程配音，此项不阻塞通关。

## 安装

### 前置

- **NVDA（推荐）**：补丁会优先通过 NVDA Controller Client 朗读，延迟最低。
  **NVDA 必须先启动**，补丁不会替你启动它。
- 没有 NVDA 也能用：会退到 **Tolk**（若 `Tolk.dll` 在场，支持 JAWS / SuperNova 等），
  再退到 **Windows SAPI**。
- 用 SAPI 兜底时，**系统里要装中文语音**，否则中文念不出来。
  检查方法：「设置 → 时间和语言 → 语音」，看有没有中文（简体）语音包。
- 本补丁依赖 **.NET 6 运行时**——不用你另外装，发布包里带了 `dotnet\`
  （BepInEx 6 自带的 mini-coreclr）。

### 步骤

**把压缩包里的东西全部拷进游戏根目录就行。没有安装程序。**

1. 在 Steam 里找到游戏 → 右键 → **管理 → 浏览本地文件**，打开游戏根目录。
   本机的实测位置是：

   ```
   D:\Steam\steamapps\common\The NOexistenceN of Lilith
   ```

   （你的 Steam 库可能在别的盘，以「浏览本地文件」打开的目录为准。
   进去后应该能看到 `Lilith.exe` 和 `Lilith_Data\`。）

2. 解压下载的压缩包。

3. **把解压出来的所有文件和文件夹，整个复制到游戏根目录**，
   提示「是否合并 / 替换」时选**是**。

   拷完之后游戏根目录应该长这样（只列补丁相关的；
   下面的目录树是照**本机已安装的 BepInEx 6.0.0-be.788** 实际结构写的）：

   ```
   The NOexistenceN of Lilith\
   ├─ Lilith.exe
   ├─ Lilith_Data\
   ├─ GameAssembly.dll
   ├─ UnityPlayer.dll
   ├─ winhttp.dll              ← 新增（BepInEx 的注入入口，UnityDoorstop）
   ├─ doorstop_config.ini      ← 新增
   ├─ .doorstop_version        ← 新增
   ├─ baselib.dll              ← 首次启动时由 BepInEx 自动生成（不在安装包里）
   ├─ BepInEx\                 ← 新增
   │   ├─ core\                （BepInEx.Core.dll、BepInEx.Unity.IL2CPP.dll 等）
   │   ├─ plugins\
   │   │   ├─ JustLilithA11y.dll
   │   │   └─ nvdaControllerClient.dll
   │   └─ config\              （首次启动后生成）
   ├─ dotnet\                  ← 新增（.NET 6 mini-coreclr，BepInEx 6 自带）
   ├─ licenses\                ← 新增，**别删**（见下）
   ├─ 安装说明.md
   └─ 常见问题.md
   ```

   > **`licenses\` 里是第三方组件的许可证与声明，请不要删。**
   > 包里带了十来个第三方二进制（BepInEx 运行时、Il2CppInterop、UnityDoorstop、
   > NVDA Controller Client、.NET 运行时等），它们的许可证要求随二进制附上
   > 许可证全文与版权行。其中 `LGPL-2.1-BepInEx.txt`、`LGPL-3.0-Il2CppInterop.txt`、
   > `LGPL-2.1-NVDA-ControllerClient.txt` 是必须带的三份，
   > `THIRD-PARTY-NOTICES.txt` 是逐作重写的声明（写明来源与获取途径）。
   > 它们不占地方（几十 KB），删掉不影响游戏运行，但会让这个包不合规。

   > **`nvdaControllerClient.dll` 会在 `BepInEx\plugins\` 和包根各放一份**：
   > IL2CPP 下 `DllImport` 走 Windows 加载器，先查应用目录，
   > 插件目录那份是常规位置，包根那份是兜底（`mod\build.ps1:167-173`）。

4. **启动游戏**。第一次启动会慢一些——BepInEx 要按本机游戏生成
   `BepInEx\interop\` 与 `BepInEx\unity-libs\`，几百个文件，之后就正常了。

5. 进游戏后应该先听到一句「无障碍补丁已加载」（配置项 `[其它] 启动时播报`）。
   听到它就说明读屏通路是通的；听不到就先翻 [常见问题.md](常见问题.md)。

> **补丁不改动任何游戏文件。** 上面新增的那些都是旁挂的，
> 游戏本体一个字节都没动。

### 关于那个黑色控制台窗口

BepInEx 默认会开一个命令行窗口显示日志。你可能会看到它闪一下。
**本补丁没有实现「隐藏控制台窗口」这一项**（平台层有该功能，本作的配置项里没有），
所以窗口会在启动时出现——不影响游戏，直接忽略即可，或者改 BepInEx 自己的配置：
`BepInEx\config\BepInEx.cfg` → `[Logging.Console]` → `Enabled = false`
（日志文件照常写到 `BepInEx\LogOutput.log`）。

### 卸载

删掉上面标「新增」的那些即可（都在游戏根目录）：

```
winhttp.dll
doorstop_config.ini
.doorstop_version
baselib.dll    ← 首次启动自动生成，可一并删除
BepInEx\
dotnet\
licenses\
安装说明.md
常见问题.md
```

只想去掉补丁、保留 BepInEx：删 `BepInEx\plugins\JustLilithA11y.dll` 就行。

> 卸载后 `BepInEx\config\justlilith.a11y.reader.cfg` 会留着（如果生成过）。
> 那只是个配置文件，留着没有坏处；不想留就一起删。

### `[朗读]`

**`朗读无配音剧情 = false`** ← **本作默认关**
本作台词**全程有配音**，读屏用户只需要界面与控制，台词交给游戏语音，不重复朗读。
打开后，没有配音的台词（节点 `soundId` 为空、台词库也查不到语音）才会由补丁念出来。
**有没有无配音行、比例多少，日志里的 `[Reader] stats` 会给，尚未逐条核对。**

**`无法判定时也朗读 = false`** ← **本作默认关**
抓不到当前行数据、或判断不了有没有配音时，默认**跳过**。
打开了才「宁可多念」。
注意：两项都关着时，对话事件**仍然会订阅**——它负责判定「这句有配音」并写日志，
只是不再调用语音合成去念台词。

**`朗读时带上说话人 = true`**
在台词前加上说话人名字（只在打开上面两项时才有意义）。旁白没有名字，不加前缀。
名字来源是 `DialogueNode.speaker` 字符串；**实际值是不是中文名尚未核对**，
如果发现念的是内部 ID，把这一项关掉即可。

**`朗读选项 = true`**
选项出现时把全部选项一次念完并编号（「有 N 个选项。选项 1：…；选项 2：…」）。
只念一遍并进重读缓冲，不会每帧重复念。**已实机验证。**

**`数字键选择选项 = true`**
选项出现时按 `1`–`9` 直接选中对应项，不必用鼠标、也不必先进入导航模式。
只做「替你按了那一个按钮」，不删选项、不改任何计时。**已实机验证。**

**`朗读界面浮动文本 = true`**
朗读**不经过对话系统**的界面文字：画面中央的提示条、开场「记忆相框」的逐句字幕等。
只扫**可见**且**不属于**对话气泡 / 台词选项 / 可导航控件的文字；
纯数字（倒计时、百分比、时间）与占位字会被过滤。
**开场「记忆相框」的字幕是否真的被抓到，尚未实机验证**（探针静态扫描 0 命中）。
若觉得念得太碎，把这一项关掉即可。

**`限时选择时长 = 20`** ← **本作没有效果（保留字段）**
反编译实查：`DialogueOption` 只有 `text` / `nextId` 两个属性，`DialogueNode` 只有 `duration`，
本作的选项**没有倒计时字段**，也就是说**没有限时选择**。
留着这个键是为了将来配置迁移时不丢键。原则不变：真有计时也只允许**拉长**、不允许取消
（到点会走沉默分支，取消掉等于删掉一个剧情分支）。

**`沉默按键 = "0"`**
只清掉**补丁自己**的待选列表，绝不碰游戏的计时器。
本作没有限时选择，所以平时按它没有可见效果（保留语义）。留空则关闭。

**`重读按键 = "Backspace"`**
重读**最近朗读过的那一段**（选项也算一段，选项刚出现时按退格会重读整组选项）。
记忆只在内存里，退出游戏即清空。
**不要填游戏原生占用的键**（游戏自带热键见下面「游戏自带的键」）。

**`语音后端 = "自动"`**
`自动` / `Tolk` / `NVDA` / `SAPI`。默认按 Tolk → NVDA → 争渡（若装了）→ SAPI
的顺序挑第一个可用的（实际链路以平台层 `Speech.cs` 为准）。
钉死某一个主要用来排查问题，例如填 `SAPI` 就能确认系统语音这条路通不通；
**钉死后不会自动降级**，那个后端不可用就彻底没声了。

**`朗读手机消息 = true`** ← **本作没有接上（保留字段）**
本作**没有手机**，但有聊天 / 备忘 / 待办类面板
（`ChatListWindow` / `ChatListRow` / `MemoView` / `Cell_MemoItem` / `Cell_TodoItem`）。
这些面板现在靠**界面导航逐控件朗读**（进导航模式后用上下键听）；
「新消息自动播报」需要实机确认行文本长什么样，**尚未实现**。

**`朗读手机表情 = true`** ← **本作没有效果（保留字段）**
表情图现在只会被当作图片控件，由导航报「图片」。

**`快进停止时补念当前句 = true`** ← **本作只有保底行为**
反编译全文检索没找到任何 skip / 快进状态属性，所以**没有独立的快进判定**。
实际行为是：同一句在 2.5 秒去重窗口内不重复念，窗口外停住的那句照常念——
这样即使游戏有快进，停下来那句也不会漏；代价是快进过程中会跟着念。

### `[界面导航]`

**`菜单键盘导航 = true`**
键盘导航总开关。

**`导航开关快捷键 = "Ctrl+Alt+Plus"`** ← **本作默认值**
进入 / 退出界面导航模式。三种写法都认：

- `Ctrl+Alt+Plus`：**主键盘加号**（= `Shift` + 主键盘 `=`），三键同按触发；
  小键盘加号不算；纯 `Ctrl+Alt` 不再触发。**默认值，已实机验证。**
- `Ctrl+Alt`：纯修饰键组合，按住约 0.25 秒触发一次，期间按了别的键就取消。
- `Ctrl+Alt+G`：组合键 + 主键，按下那一帧触发。
- `Tab`：单键，等于平台层原本的默认行为（兜底仍生效）。

**为什么不用纯 `Ctrl+Alt`**：本作自带 **9 条 `Ctrl+Alt+字母` 热键**
（`Ctrl+Alt+L` 强制点击穿透、`Ctrl+Alt+S` 静音、`Ctrl+Alt+N` 随手记、`Ctrl+Alt+B` 详细备忘、
`Ctrl+Alt+R` 提醒事项、`Ctrl+Alt+P` 番茄钟、`Ctrl+Alt+T` 计时、`Ctrl+Alt+K` 闹钟、
`Ctrl+Alt+M` 音乐播放器），纯 `Ctrl+Alt` 会和它们冲突；加号不在游戏热键表里，
而且主键盘 `=` 上的加号还要多按一个 `Shift`，误触概率最低。
写错了会自动退回 `Tab` 并在日志里提示。

**`快捷键全局生效 = true`** ← **本作必须开**
游戏窗口没有焦点时也响应导航开关键、方向键、回车、数字键。
本作的窗口带 `WS_EX_NOACTIVATE`（永远拿不到键盘焦点），默认还开着「单击穿透」，
只靠游戏内的输入系统**一个按键都收不到**——关了这项，导航和数字键会全部失效。
实现方式是读系统键盘状态（`GetAsyncKeyState`），不装键盘钩子、不注入、不拦键；
游戏自己该收到的按键照样收到。

**`按屏幕位置排序控件 = true`**
按控件在屏幕上的位置排（先上后下、同一行先左后右），让「第几项」和画面对得上。
关掉则改回按渲染层级排序——顺序就和画面不一致了，除非有特别理由，别关。

**`只导航看得见的控件 = true`**
只把画面上真正能看到、能点到的控件纳入导航。
游戏里常有「激活着但停在画面外或被面板挡住」的控件，不筛会导航到看不见的东西上。
只有发现正常按钮被误排除时才需要关掉。

**`退出前二次确认 = true`**
「退出游戏」只按一下就关掉整个会话，读屏用户分不清它和旁边的按钮，
所以补一道确认：第一次回车只念一句确认，再按一次才真退；按方向键取消。

**`退出确认对象名 = "quitGameButton"`**
哪些控件需要上面那道确认，按 Unity 对象名**全等**匹配，逗号分隔。
默认值来自反编译实查（`SettingView.cs:264` 的 `quitGameButton`，莉莉丝面板的退出按钮）。
名字不准时以日志里打印的对象名为准。

**`排除的对象名 = ""`**
这些对象**及其整棵子树**里的控件不纳入导航（按祖先链匹配）。
用途是把画面噪音（装饰按钮、社交链接条）从导航里摘掉。留空则不过滤。

**`朗读原始控件名 = false`**
控件读不到任何文字时，退化成念 Unity 对象名 / 类型名 / ID。
**不是给玩家用的开关**：这些名字（`CommonCloseButton`、`Button (6)`、`CCPlus`）
要么不像人话，要么同名控件在不同面板里含义完全不同，念出来比不念更误导。
默认行为改念结构化描述（如「未命名按钮，第 3 项，共 7 项，面板设置」）。
只在排查「这个控件到底是什么」时临时打开，同时把「界面诊断日志」打开看原始名。

**`推断标签激活前确认 = true`**
当控件的标签是**推断**出来的（结构化描述或原始对象名，不是界面上真有的文字），
第一次激活只朗读并提示，再按一次才真正执行。
理由：读屏玩家分不清「未命名按钮，第 2 项」和旁边那个「确定」，
按错可能直接存档 / 覆盖 / 返回标题。8 秒不确认失效，换项或退出导航即清除。

### `[其它]`

**`启动时播报 = true`**
启动后念一句「无障碍补丁已加载」，用来确认读屏通路是通的。

**`界面诊断日志 = false`**
把进入导航模式时扫描到的控件写进 `LogOutput.log`，排查导航范围用。
排查完请关掉，否则日志会很大。
> ⚠️ **日志会含台词原文，不要公开**——
> 台词是游戏著作权内容，公开日志等于再分发剧本（见仓库 README 的「合规说明」）。

**`挂载 Harmony 台词补丁 = false`**
给台词朗读加第三条腿：用 Harmony 直接拦 `DialogueManager.Say`。
默认关——正常情况下事件订阅已经够用，它只在「事件全线失效」时做排查 / 兜底。
打开后日志会出现 `[Patches] 已挂载 …`，台词的 `path=` 会变成 `say-patch`。
**平时别开**（可能多念临时台词）。

## 出问题时

**一点声音都没有。**
先确认 NVDA 已经开着。然后看 `<游戏目录>\BepInEx\LogOutput.log`，
开头会有「语音后端就绪: …」或「语音不可用: …」。若写着「语音不可用」，
后面会跟每个后端的失败原因；也检查一下系统里有没有中文语音。

**有启动播报，但进剧情后不朗读台词。**
**这是本作的默认设计**，不是故障：台词全程有配音，交给游戏语音念，
补丁不重复朗读。想让它念无配音行，把配置里
`[朗读] 朗读无配音剧情` 和 `无法判定时也朗读` 打开（效果尚未逐句核对）。

**菜单里方向键没反应。**
先按 **`Ctrl+Alt+Plus`**（主键盘加号，即 `Ctrl+Alt+Shift+=`）进导航模式；
检查配置 `[界面导航] 导航开关快捷键` 是不是被改过、`快捷键全局生效` 是不是被关掉。
如果仍然没反应，把 `[其它] 界面诊断日志` 打开，重启，进一次菜单再退出，
把 `LogOutput.log` 里 `[诊断]` 那几行发给我们。

**生日那一行的开关按下去了，却只是展开日历。**
这是已知不足：生日行的 `SwitchBtn` 是**展开器**不是开关，「生日」行的状态语义还没修好；
展开后的日历格目前念「14，按钮」，没有「14 日」这样的语义。

**「你的名字」那一行，念成了「你的名字，按钮」。**
这也是已知不足：`Btn_FolderSelect` 被上方行标题覆盖，真实含义是「选择文件夹」。

**黑窗口跑出来。**
见上面「关于那个黑色控制台窗口」。

**游戏启动变慢 / 卡在启动画面。**
第一次启动要生成 interop，几分钟都可能；之后就快了。
如果**每次都**很慢，检查是不是装了两套 BepInEx（比如游戏根目录和 `BepInEx\` 里
各有一份 `winhttp.dll`），或者 `BepInEx\interop\` 被清掉了。

**游戏更新之后补丁失效了。**
游戏更新会改 `GameAssembly.dll`，interop 与补丁点可能一起失效。
把 `BepInEx\interop\` 删掉让 BepInEx 重新生成，然后等补丁更新。

## 已验证到什么程度

**截至 2026-10-22，在游戏里真的跑通过的事情**（有当天日志与操作记录）：

- 补丁加载、启动播报正常；
- 进导航模式（`Ctrl+Alt+Plus`）后在**设置面板**逐项走过 8 个 tab
  （其他 / 快捷键 / 我 / 莉莉丝 / 语言 / 声音 / 图像 / 控制），
  读法：「游戏时不显示，开关，关，按钮」「对话显示速度，滑条，50%」
  「简体中文 ▼，按钮」「你的名字，输入框，当前内容 …」「关闭 / 单曲 / 选择文件夹」；
- **回车**激活 tab 后重新扫描并播报「界面已更新」；
- **选项**弹出时念「有 N 个选项。选项 1：…」，**数字键**能选中；
- 退出导航后，游戏自带热键 `Ctrl+Alt+M` 照常打开音乐播放器（不抢键）。

**明确还没有验证的事**（诚实清单，不是谦虚）：

- 导航内**方向键移动**、**滑块左右调**、**PageUp/PageDown 分组**——
  本轮自动化注入不了方向键，只有「回车激活」实测过；
- **生日日历格**的日期语义（当前念「14，按钮」）、`Btn_FolderSelect` 的标签；
- **台词朗读**（本作全程配音，默认关；打开后的效果没逐句核对）；
- **配音判定**的逐句准确性（`ResolveNodeSoundId` 是不是每句都给出 id）；
- **开场「记忆相框」字幕**能不能被 `朗读界面浮动文本` 抓到（探针静态扫描 0 命中）；
- **聊天 / 备忘 / 待办**面板的逐项导航（面板能导航，但没有逐面板核对读法）；
- **到底哪个语音后端在出声**（NVDA / Tolk / SAPI 是哪一个，日志里有，但没逐项确认）；
- **最终用户视角的完整流程**（从标题到通关，没有走完过）。

如果你愿意当测试者：照 `测试问卷.md` 走一遍，把
`BepInEx\LogOutput.log` 发给我们。**问卷里凡是没有复测的项目，请写「尚未实机复测」，
不要凭印象打勾。**

## 这个包里没有什么

- **没有游戏资源**：没有剧本、没有图片、没有音频、没有字体。
- **没有 interop 与 unity-libs**：那是 BepInEx 首次运行时按本机游戏生成的，
  不能由我们分发。
- **没有 `BepInEx\config\` 里的玩家配置**。
- **没有争渡（ZDSR）的 `ZDSRAPI.dll`**：那是专有软件，需要你自己装争渡读屏，
  补丁只会在装了的机器上自动找。
